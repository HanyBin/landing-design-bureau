 🏛 Forma Studio — Architecture & Interior Design Landing Page

> A clean, typographic single-page landing for an architectural studio. Built with pure HTML & CSS — no frameworks, no dependencies.

🔗 **[Live Demo](https://hanybin.github.io/landing-design-bureau/))**

---

## ✨ Features

- **Scroll-triggered reveal animations** — sections fade up as you scroll
- **Sticky navigation** with blur backdrop and border on scroll
- **Fully responsive** — mobile, tablet, desktop
- **Working contact form** with success state
- **Hover interactions** on project cards and service blocks
- **Respect for `prefers-reduced-motion`** — animations disabled for users who prefer it
- **No JavaScript frameworks** — vanilla JS only (~40 lines)
- **Google Fonts** — Cormorant Garamond + Inter

## 🌐 Deploy to GitHub Pages

1. Push to GitHub
2. Go to **Settings → Pages**
3. Set source to `main` branch, `/ (root)`
4. Your site is live at `https://hanybin.github.io/landing-design-bureau`

## 🎨 Design Decisions

| Decision | Rationale |
|---|---|
| Cormorant Garamond display | Gives editorial weight without heaviness |
| Indigo `#4F5BD5` accent | Cool, distinctive — avoids the typical terracotta/clay |
| Vertical side label in hero | Signature element — architectural detail language |
| No card shadows | Flat surfaces feel more considered and contemporary |
| Grid-based section layout | Structural consistency matches the architectural subject |
